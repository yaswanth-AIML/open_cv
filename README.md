OpenCV Face & Eye Detection
📌 Overview
The OpenCV Project demonstrates real‑time face and eye detection using Python. It leverages Haar Cascade Classifiers to identify multiple faces and eyes in both images and video streams, making it a practical introduction to computer vision.

🚀 Features
Detect faces in real‑time using webcam.

Highlight detected faces with bounding boxes.

Detect eyes within faces.

Works on both images and video streams.

Can track multiple people simultaneously.

🛠️ Tech Stack
Language: Python

Libraries:

opencv-python (OpenCV)

numpy
